Models

Every model the scene builder can place, by kit. Regional packs ("packs") are built procedurally at load; Blender kits ("assets", "extraAssets") are bundled. Trees come in three levels of detail (name, -lod, -far). Each thumbnail is framed to fit, with a 1.8 m person beside it so scale errors show (style rule: trees full height, ground cover below the knee, boulders 1–2 m).

Surfaces

Procedural materials in js/world/toolbox/materials: no image textures, world-space so they never stretch.

Palettes

Every route's and preset's palette. New routes take 6–10 muted colours from the real place.

Scene fields

Every field a scene can use, the toolbox module that reads it, and the scenes that use it now (from js/world/toolbox/scene-schema.js; npm run lint:scenes checks scenes against it).
